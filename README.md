<h1 align="center">Solve Labyrinth</h1>

<p align="center">
An interactive <strong>maze generator and solver</strong> built with JavaScript,<br>
powered by the <a href="https://github.com/qiao/PathFinding.js">PathFinding.js</a> library.
</p>

<hr>

<h2>Features</h2>

<ul>
  <li><strong>Random Maze Generation</strong> – Generates a unique maze every time</li>
  <li><strong>Pathfinding Solver</strong> – Uses the A* algorithm</li>
  <li><strong>Simple Gameplay</strong> – Users can solve the maze themselves</li>
  <li><strong>Visual Path Display</strong> – A button displays the solution for the maze</li>
</ul>

<hr>

<h2>Built With</h2>

<ul>
  <li>JavaScript</li>
  <li>HTML5</li>
  <li>CSS3</li>
  <li><a href="https://github.com/qiao/PathFinding.js">PathFinding.js</a></li>
</ul>

<p>
I used the A* (A star) pathfinding algorithm from the PathFinding.js library to optionally display the solution of the maze.
</p>

<hr>

<h2>How It Works</h2>

<ol>
  <li>A maze is generated using my own simple maze generation algorithm</li>
  <li>The maze grid is then drawn on the canvas for the user to see</li>
  <li>The A* algorithm finds the only possible path to reach the end</li>
  <li>The user can press a button to reveal the solution!</li>
</ol>
